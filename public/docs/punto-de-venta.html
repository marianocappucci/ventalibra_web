Punto de venta

Vender rápido: buscá por nombre o escaneá el código de barras, agregá a la venta y confirmá.

Armar una venta

  1. Andá a Punto de venta.
  2. Buscá el producto por nombre, o escaneá su código de barras — si el código no resuelve nada, el sistema cae automáticamente a la búsqueda por nombre.
  3. Si el producto tiene variantes, elegí la variante correspondiente (talle/color).
  4. Ajustá la cantidad (admite decimales para productos pesables).
  5. Repetí para cada producto de la venta.

Confirmar la venta

Elegí la sucursal y el medio de pago (obligatorio, incluso si no facturás — ver Caja). Si tenés facturación activa (plan Estándar o superior), podés tildar "Emitir factura" en este paso.

Tip: el precio de cada línea se resuelve automáticamente según la lista de precio configurada — ver Listas de precio.

Qué pasa al confirmar

Al confirmar, el stock del producto (o de la variante puntual) se descuenta automáticamente y queda un movimiento de caja registrado.
