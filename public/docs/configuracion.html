Configuración

Datos del comercio, logo, correo, facturación, balanza, ticket y copias de seguridad. Todo en una pantalla, sólo para administradores.

Dónde está

En el menú lateral, Configuración. Tiene seis secciones; se cambia entre ellas con las pestañas de arriba. La sección abierta queda en la dirección del navegador, así que se puede guardar un favorito o pasar el link de una sección puntual.

Antes eran tres pantallas sueltas —ARCA, Balanza y Ticket— y no había dónde cargar los datos del comercio ni bajarse una copia. Ahora están todas juntas. Los enlaces viejos siguen funcionando: llevan a la sección correspondiente.

Logo

En la misma sección. Se sube un PNG o JPG. Se puede reemplazar por otro o quitarlo en cualquier momento.

Correo

La configuración del servidor de correo saliente (SMTP): servidor, puerto, usuario, contraseña y el remitente que ven los destinatarios.

Sin esto, la recuperación de contraseña no funciona. Si un cajero olvida la suya y pide el enlace de recuperación, el sistema responde que el envío de correo no está configurado.

La contraseña se guarda cifrada. Al editar el resto de los datos no hace falta volver a tipearla.

ARCA

Los datos de facturación electrónica: CUIT, punto de venta, ambiente (homologación para probar, producción para facturar de verdad) y la ubicación del certificado y la clave privada en el servidor. Ver Facturación electrónica.

Balanza

El formato de la etiqueta que imprime la balanza de mostrador. Incluye un probador: se escanea una etiqueta real y se ve al instante qué producto y qué peso entendió el sistema.

Probá con una etiqueta de verdad antes de abrir. Es la única forma honesta de saber si la configuración quedó bien sin arriesgar un cobro equivocado.

Ticket

Cómo sale el ticket impreso: ancho del rollo, tamaño de letra y texto al pie. Tiene vista previa — se mira antes de gastar rollo.

Datos / Backup

Acá el comercio se baja una copia de sus datos, sin depender de nadie.

Descargar una copia

Descargar copia genera y baja un archivo .zip en el momento. Adentro van las bases de datos completas —el catálogo, el stock, las ventas y los usuarios del sistema— y los archivos, como el logo.

Guardala fuera del servidor. Una copia que vive en el mismo lugar que el original no protege de nada.

Copias guardadas en el servidor

Guardar copia en el servidor deja una copia del lado del sistema, que después se puede descargar desde la lista. Se conservan las 10 más recientes; al llegar a ese número se borra la más vieja.

En la lista también aparecen las que hace el sistema solo: las que se llaman antes_restore se generan automáticamente justo antes de restaurar.

Restaurar

Reemplaza todos los datos actuales por los del archivo que se suba. Es la operación más delicada del sistema, así que:

  • Elegir el archivo no restaura nada: primero aparece un aviso con el nombre del archivo y hay que confirmar.
  • Antes de tocar nada, el sistema guarda solo una copia del estado actual y te dice cómo se llama.
  • Si el archivo está dañado o es de otro sistema, se rechaza y no se toca ningún dato.
