Balanza de mostrador

Vender por peso con las etiquetas que imprime la balanza: configurarla una vez, cargarle el código a cada producto y escanear.

Cómo funciona

La balanza de fiambrería o verdulería imprime una etiqueta con un código de barras de 13 dígitos que no identifica un producto único: lleva adentro qué producto es y cuánto se pesó (o ya el importe calculado). Al escanearla, el POS agrega la línea con ese producto y esa cantidad.

El formato lo define la marca y cómo esté configurado el equipo, así que se carga una vez en el sistema y se prueba con una etiqueta real.

Configurar el formato

  1. Andá a Administración → Configuración → Balanza.
  2. Tildá El local usa balanza con etiquetas.
  3. Completá los campos de la tabla de abajo. Si no sabés cuál usa tu equipo, dejá los que vienen y probá una etiqueta real.
  4. Tocá Guardar.
CampoQué es
PrefijoCon qué dígitos empiezan las etiquetas de la balanza. Casi siempre 20.
Qué trae la etiquetaEl peso (el importe lo calcula el sistema con el precio por kilo vigente) o El importe ya calculado (se cobra lo que dice la etiqueta, aunque el precio del sistema haya cambiado).
Dígitos del código de productoCuántos dígitos usa la balanza para identificar el producto.
Dígitos del peso (o del importe)Cuántos dígitos ocupa el valor.
Largo total del código13 en un EAN-13, 8 en un EAN-8.
Unidad mínimaCómo leer los dígitos: Milésimos (gramos), Centésimos (centavos), Décimos o Enteros. Con milésimos, 00750 se lee como 0,750 kg.

Debajo de los campos, el sistema cuenta los dígitos (prefijo + código + valor = N dígitos usados, M para el verificador). Si no entran en el largo total, avisa No entra.

Probar una etiqueta

Con la balanza activada aparece Probar una etiqueta. Pesá algo, escaneá la etiqueta en el campo y tocá Probar: no registra ninguna venta.

  • Si está bien, muestra el nombre del producto y el Peso leído (por peso) o el Importe impreso en la etiqueta (por importe).
  • Si dice que se leyó como código de barras común, el prefijo o el largo no coinciden con el de la balanza.
  • Si el producto no aparece, falta cargarle el código (ver abajo).

Probá con una etiqueta de verdad antes de abrir. Es la única forma de saber que la configuración quedó bien sin arriesgar un cobro equivocado.

Cargar el código de balanza en cada producto

  1. Andá a Catálogo y precios → Productos, buscá el producto y tocá Gestionar códigos y variantes.
  2. En Códigos, elegí el Tipo Balanza y escribí en Código el número con que ese producto está cargado en la balanza, sin los ceros de la izquierda (12 para 00012).
  3. Tocá Agregar.

Para vender por peso, la Unidad del producto tiene que admitir fracciones (por ejemplo, kilogramo). El Precio de venta es el precio por esa unidad. Si el producto se cuenta por unidad, el sistema no deja venderlo por peso y avisa que no admite fracciones.

Vender con la balanza

  1. Escaneá la etiqueta en el POS. La línea entra con el peso (por ejemplo, 0,750) y su importe.
  2. Seguí escaneando o tocá Cobrar.
  • La cantidad de una línea de balanza no se cambia. La fija la etiqueta y, al cobrar, el servidor la valida contra ella. Para llevar más, escaneá otra etiqueta; para corregir, quitá la línea y escaneá de nuevo.
  • Los kilos de una línea de balanza cuentan para el quiebre por cantidad del producto, pero el precio de una etiqueta por importe no se modifica.
  • Una etiqueta que no corresponde al producto o con cantidad cambiada se rechaza al cobrar.

Una etiqueta por importe vale lo que dice. Si el precio cambió en el sistema después de imprimirla, se cobra el importe impreso: es el que ve el cliente en el paquete.
