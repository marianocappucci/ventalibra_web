Catálogo

Productos y servicios, con sus códigos, variantes, marca de vencimiento y parámetros de reposición: la base de todo lo demás.

Unidades y categorías

Antes de cargar productos, revisá en Administración → Configuración las secciones Unidades de medida y Categorías.

  • Unidades: cada una tiene Código, Nombre, Fracción (si admite cantidades con decimales, como kilogramo o litro) y Decimales. Agregás una con + Nueva unidad.
  • Categorías: se agregan con + Nueva categoría y se pueden desactivar. Un producto sólo puede llevar una categoría que exista y esté activa.

Productos

En Catálogo y precios → Productos se ve la lista, con buscador (por nombre, código o categoría) y el stock total de cada producto sumando todos los depósitos.

Crear un producto

  1. Tocá Nuevo producto.
  2. Completá Nombre (obligatorio), Código (el de barras o uno interno; podés dejarlo vacío y agregar códigos después), Categoría y Unidad.
  3. Elegí el Tipo: Producto o Servicio.
  4. Cargá el Precio de venta y el Precio de costo. Con ambos, el sistema muestra el Margen en porcentaje.
  5. Completá el Stock mínimo si querés que el sistema avise cuando baje de ahí (cero es «no me avises»).
  6. Opcionales: Descripción, la marca Vence y los datos de Reposición sugerida (más abajo).
  7. Tocá Crear producto.

Para cambiar algo, usá Editar producto en su fila.

Lo que conviene saber

  • Producto o servicio se elige al crear y no se cambia. Un servicio (flete, instalación) se vende como cualquier otro pero no tiene inventario ni lotes.
  • La unidad se bloquea cuando el producto ya tiene movimientos de stock, ventas o compras: cambiarla cambiaría el significado de todo lo registrado.
  • Un producto no se elimina: se desactiva con Producto activo. Desactivado deja de ofrecerse en la búsqueda del POS, pero conserva todo su historial.
  • El código no se repite. Si ya existe, el sistema avisa Ya existe un producto con el código «…» y no guarda nada.
  • El costo es reservado: sólo lo ven el administrador y el encargado. Para los demás roles el sistema ni siquiera lo recibe. Ver Usuarios y roles.
  • Precios y costos no pueden ser negativos.

Códigos y variantes

En la fila del producto, Gestionar códigos y variantes abre dos secciones.

Códigos

Un producto puede tener varios códigos, cada uno con su Tipo: Interno, Código de barras, SKU, Balanza u Otro. Se agregan con Agregar. Escanear cualquiera de ellos en el POS resuelve el producto. El tipo Balanza es el que usan las etiquetas de la balanza.

Variantes de talle y color

  1. En Variantes (talle/color) escribí el SKU y el Nombre (por ejemplo, M / Azul).
  2. Tocá Agregar. Repetí por cada variante.
  • Cada venta de una variante queda registrada con su variante: el sistema sabe cuánto salió de cada talle o color. La pantalla de Stock muestra el total del producto, sumando todas sus variantes.
  • Las variantes comparten el precio del producto: no tienen precio propio. Una promoción o un quiebre por cantidad del producto alcanza a todas, y sus unidades se suman para el quiebre.
  • En el POS, al agregar un producto con variantes, el sistema pregunta cuál. Si escaneás el SKU de una variante, entra directo.
  • Si el producto no necesita variantes, no cargues ninguna.

Productos que vencen

Activá Vence (maneja lotes y fecha de vencimiento) en el producto perecedero. Desde ese momento se le pide lote y fecha al recibir mercadería, las salidas descuentan del lote que vence primero, el POS avisa si vendés algo vencido o por vencer, y aparece en Vencimientos y lotes. Ver Vencimientos y lotes.

Marcar o desmarcar un producto es decisión del encargado o del administrador. Un servicio no puede vencer.

Reposición sugerida

Si tu rol lo permite, el formulario del producto trae el bloque Reposición sugerida, con los datos propios de ese producto que usa la reposición:

CampoQué hace
Stock mínimoEl piso global: si lo que hay más lo que viene en camino queda por debajo, el sistema sugiere pedir lo que falta.
Mínimo por sucursal (Mínimo en <sucursal>)Un mínimo propio para cada sucursal. Vacío, usa el global. Aparece al editar, con dos o más sucursales.
Plazo de entrega (días)Cuánto tarda este producto en llegar (de 1 a 180). Vacío, rige el plazo general de la pantalla de reposición.
Stock máximoEl techo: lo que hay más lo que ya viene en camino no pasa de acá. No puede ser menor que el stock mínimo. Vacío, sin tope.
Proveedor habitualA quién se le compra normalmente. Es una preferencia: sirve para filtrar la reposición y para armar las órdenes de compra en borrador, una por proveedor.

Etiquetas de góndola

Cuando cambian los precios, el cartel de la góndola tiene que cambiar con ellos. Desde Catálogo y precios → Productos → Etiquetas:

  1. Buscá los productos con Buscar producto o filtrá por Categoría.
  2. En Precio elegí de dónde sale el precio: Precio de venta del producto o una lista. La lista predeterminada es la que cobra el POS.
  3. Tildá los productos, o tocá Elegir los N que se ven. Quitar la selección los destilda.
  4. Tocá Ver e imprimir, elegí Columnas (2, 3 o 4) y tocá Imprimir.

Sale una hoja A4 para recortar, con nombre, precio y código de barras de cada producto. Un producto sin código sale igual, sin barras.

La etiqueta dice el precio base de la lista. No resuelve los quiebres por cantidad ni las promociones por fecha, que dependen de cuándo y cuánto se compre. Tampoco está pensada para una impresora de rollo.

Quién puede qué

  • Administrador y encargado: crean y editan productos.
  • Vendedor: consulta el catálogo, sin costos.
  • Depósito: no crea ni edita el producto, pero carga su reposición (plazo, stock máximo, proveedor y mínimos por sucursal) sin ver el costo.
  • Cajero: busca productos desde el POS, no tiene la pantalla de Productos.
