Catálogo

Unidades, productos, códigos de barra y variantes — la base de todo lo demás en VentaLibra.

Unidades

Definí las unidades con las que vendés (unidad, kilogramo, litro). Una unidad puede marcarse como "vendible por fracción" para productos pesables (fiambres, verdulería) — ahí las cantidades admiten decimales.

Productos

Cargá nombre, unidad, categoría y precio de venta por defecto. Este precio es el que se usa si no hay una lista de precio configurada para ese producto.

Códigos de barra

Agregá uno o más códigos de barra a cada producto desde su ficha. En el punto de venta, escanear un código resuelve el producto exacto al instante.

Variantes de talle y color

Si vendés indumentaria, cada producto puede tener variantes (por ejemplo, talle S/M/L, color). Cada variante lleva su propio stock, completamente independiente del resto.

Tip: si un producto no necesita variantes (por ejemplo, un producto de almacén), simplemente no cargues ninguna — funciona igual que antes.
