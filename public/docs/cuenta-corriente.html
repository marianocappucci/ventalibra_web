Cuentas corrientes

Quién te debe, cuánto, y el recibo de cada cobranza.

Quiénes deben

La pantalla Cuentas corrientes abre con la lista de clientes con saldo pendiente y el monto de cada uno. Un cliente aparece acá cuando una venta se cobró total o parcialmente a cuenta.

La cuenta de un cliente

Al entrar a un cliente se ven sus movimientos —lo que se le vendió a cuenta y lo que fue pagando— y el saldo resultante.

Registrar una cobranza

  1. Entrá a la cuenta del cliente.
  2. Cargá el monto que está pagando y el medio de pago.
  3. Confirmá. El saldo se actualiza en el momento.

Es un pago de deuda vieja, no una venta nueva. No genera productos ni descuenta stock: sólo cancela lo que ya se había vendido a cuenta.

El recibo

Cada cobranza puede emitir su recibo: un comprobante numerado, con los datos de tu comercio y del cliente, el monto y el medio de pago. Se descarga en PDF y se puede imprimir o mandar.

El recibo se emite una sola vez. Si volvés a pedirlo para el mismo pago, el sistema devuelve el que ya existía en vez de generar uno nuevo con otro número — un pago no puede tener dos recibos distintos dando vueltas.

Para que el recibo salga con tus datos y tu logo, completá la sección Empresa de Configuración. Si quedan vacíos, el comprobante sale sin datos del emisor.
